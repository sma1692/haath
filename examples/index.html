haath examples

Each example is a single page that loads haath from dist/. Run npm run build after changing src/.

  • 01 · Three.js WebXR scene with signs, punch and slap hits, and a hold-to-confirm. Needs a headset or example 04.
  • 02 · IWSDK systems Code-only HandSystem, MenuSystem, and CombatSystem for @iwsdk/core.
  • 03 · Pose playback No headset. Synthetic hands through updateFromPoses().
  • 04 · PC hand emulator Example 01 on a desktop with IWER hands and the haath emulator panels.
